Comprueba que la descarga es la original

La huella SHA-256 identifica el archivo. Si la tuya es distinta, no lo ejecutes y vuelve a descargarlo.

c8acc62d41f91a740f9298db84904bdb5513043ce26fc97e62c727a5fee55c4d

Para calcular la tuya, abre PowerShell en la carpeta de descargas y escribe:

Get-FileHash .\Estudio-Setup-0.3.3.exe -Algorithm SHA256

Si Windows dice «Windows protegió su PC»

El instalador aún no lleva firma digital de editor, así que SmartScreen lo muestra como aplicación poco habitual. No indica que contenga un virus: se resuelve en dos clics.

  1. Windows protegió su PC

    Microsoft Defender SmartScreen impidió el inicio de una aplicación no reconocida.

    Más información No ejecutar

    Pulsa «Más información». Es un enlace de texto, no un botón, en el centro de la ventana.

  2. Windows protegió su PC

    Aplicación: Estudio-Setup-0.3.3.exe
    Editor: Editor desconocido

    Ejecutar de todas formas No ejecutar

    Pulsa «Ejecutar de todas formas». Antes comprueba que el nombre del archivo es el que descargaste de esta página.

Requisitos

Sistema
Windows 10 o Windows 11, 64 bits.
Permisos
No hacen falta. Se instala en tu carpeta de usuario.
Espacio
Unos 1 GB para el programa. Los componentes opcionales se descargan después desde Ajustes: Remotion unos 1,5 GB, Whisper unos 0,7 GB y la voz Qwen3-TTS unos 8 GB.
Conexión
Solo para instalar los componentes y para buscar actualizaciones.
Tarjeta gráfica
La voz Qwen3-TTS necesita una GPU NVIDIA. Sin ella, utopiareel te avisa y puedes usar otra voz.

Licencias y avisos

utopiareel incluye software de terceros, entre ellos FFmpeg bajo GPLv3. Lee los avisos de licencias; también están dentro del programa, en Ajustes, en Versión.

Esta página solo aloja el instalador. Las actualizaciones se descargan desde aquí, desde Ajustes, con la misma huella.
